## 🌟 Giới Thiệu Sản Phẩm
**TroViet Pro** là giải pháp phần mềm quản lý nhà trọ, phòng trọ, căn hộ mini khép kín và căn hộ dịch vụ được tối ưu hóa 100% cho thị trường và thói quen kinh doanh tại Việt Nam.

Hệ thống giúp chủ nhà trọ, quản lý tòa nhà tiết kiệm đến **90% thời gian** ghi chép chỉ số điện nước, tính toán hóa đơn, in phiếu thu và thu hồi công nợ tự động qua **VietQR Napas 247**.

## 🛠️ Hướng Dẫn Cài Đặt 1-Click

### 🪟 Trên Windows (Dành cho Chủ Nhà Trọ)
1. Mở **PowerShell** trên Windows và dán 1 dòng lệnh duy nhất:
```powershell
irm https://raw.githubusercontent.com/justpassingByte/troviet-pro/main/install.ps1 | iex
```
2. Hoặc nhấp đúp chuột vào file `Mo-TroViet.bat` trong thư mục để mở ứng dụng ngay!

### 🐧 Trên Linux VPS (Dành cho Triển Khai Cloud 24/7)
```bash
curl -fsSL https://raw.githubusercontent.com/justpassingByte/troviet-pro/main/install.sh | bash
```
